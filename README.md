# pipefont

Pipe filesystem font paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/pipefont/

## Install / run

```bash
git clone https://github.com/theworker02/pipefont.git
cd pipefont
node src/cli.js
node --test
```
